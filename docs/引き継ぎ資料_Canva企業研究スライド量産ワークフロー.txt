─────────────────────────────
0. 最初に：引き継ぎの前提（重要）
─────────────────────────────
・CanvaのMCP連携は「セッション単位」で張られる接続です。接続そのものをコマンドやファイルで
  別環境へコピーすることはできません。
・したがって引き継ぎとは「新しい環境（Claude Code）で同じCanva MCPを接続し直し、同じ手順を
  再現すること」を指します。この資料はそのための再現手順書です。


─────────────────────────────
1. Claude Code側でCanva MCPを接続する
─────────────────────────────
1. Claude Code を Opus 4.8 で起動する
2. Canva の MCP サーバーを登録する
   ・Canva公式のMCPコネクタ（Canva Connect）を使う
   ・接続時にブラウザでCanvaアカウントへのログイン＆認可が求められるので許可する
   ・使用するCanvaアカウントは必ず本人のもの（syukatu.youtien@gmail.com）
3. 接続後、以下のツールが使えることを確認する（代表例）
   ・create-design（ブリーフ＋アウトラインからデザイン生成）
   ・search-designs / search-brand-templates（既存デザイン・テンプレ検索）
   ・create-folder / move-item-to-folder（フォルダ整理）
   ・autofill-design（ブランドテンプレートに値を流し込む＝将来の量産用）
   ・export-design（PDF等で書き出し）

※接続方法のUIは時期により変わるため、不明な場合はClaude Codeに
　「CanvaのMCPを接続したい」と伝えれば案内が出ます。

3. 量産プロンプト（これをClaude Codeに貼る）
─────────────────────────────
以下をそのまま貼り、【】内を企業ごとに差し替えて使う。

----------（ここからコピペ）----------
新卒就活生向けのYouTube動画用「企業研究スライド」をCanva上に直接作成してください。

対象企業：【企業名】

手順：
1. まずWeb検索で最新情報（直近の決算数値・ニュース・中期経営計画）を確認する。
   数値には出典（決算資料・公式サイト・報道）を必ず添える。推測は「推測」と明記する。
2. 次の構成でアウトラインを作る（各スライドは詰め込みすぎない）：
   ・表紙（企業名＋一番のインパクトある数字）
   ・アジェンダ
   ・会社情報の要点
   ・経営状況（直近3年の売上/利益率の推移を数値で）
   ・強み（3つ）
   ・弱み・課題（3つ）
   ・最近のトレンドと中期経営計画
   ・志望動機・キャリアの切り口（複数）
   ・面接想定質問
3. Canvaのcreate-designツールで、format="Presentation"、上記アウトラインを渡して生成する。
   デザインのトーン：白背景＋黒の太字タイトル、タイトル下に横線、本文は「・」の箇条書き、
   重要キーワードは青や赤で強調。就活生が一目で分かるシンプルな日本語スライド。16:9横向き。
4. 生成後、作業フォルダ（folder_id：FAHZ374XCqk）へ move-item-to-folder で格納する。
5. 完成したら編集リンクを教えてください。

補足：数値・事実には出典を明示。ロゴ・写真・イラストは著作権の都合で自動では入れず、
Canva側で素材を差し込む運用とする。
----------（ここまでコピペ）----------


─────────────────────────────
4. デザインのトーン仕様（紫枠Canvaテンプレ準拠）
─────────────────────────────
・外枠：紫(#8B5CF6)→水色(#22D3EE)のグラデーション、内側は白
・タイトル：中央・黒太字・下に黒い横線（装飾バーは使わない）
・本文：全角「・」の箇条書き
・強調：重要キーワードだけ青(#2E6FE8)／赤(#E8384F)で着色
・比較や数値：白黒の表、重要セル/列は赤枠で強調／上に黒のリード文
・フォント：日本語ゴシック（元デザインの明朝に寄せたい場合はCanvaで一括変更）
・サイズ：16:9（1920×1080相当）


─────────────────────────────
5. 動画原稿のフォーマット
─────────────────────────────
・スライド構成に沿って「約9分・話し言葉ベース」で書く
・各パートに想定尺（秒）を書く
・1分あたり約300〜330字で約9分になる分量
・冒頭フックは一番インパクトのある数字から入る
・専門用語には必ず一言の補足を入れる
・数値の出典を明記、推測は「推測」と区別
（完成例：MUFG_動画原稿.txt を参照）


─────────────────────────────
6. 将来の効率化：ブランドテンプレート化
─────────────────────────────
・現状はcreate-designで毎回ゼロから生成している（デザインが毎回微妙に変わる）
・理想は、紫枠デザインをCanvaで「ブランドテンプレート」として登録し、
  autofill-designでテキストだけ流し込む方式。これで毎回まったく同じ見た目で量産できる。
・手順：Canvaでテンプレ化 → get-brand-template-dataset でデータ項目を確認 →
  autofill-design で企業ごとの値を流し込む
・テンプレ登録はCanva Proのブランドテンプレート機能が必要（要確認）
